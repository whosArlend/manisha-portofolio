# Manisha Portfolio

A premium, editorial-style personal portfolio website for a professional content creator. Built with React, TypeScript, Vite, Tailwind CSS v4, and Framer Motion.

## ✨ Design Philosophy

Inspired by luxury brands like **Rhode**, **Dior Beauty**, **Glossier**, and **Chanel Beauty** — this portfolio communicates elegance, creativity, and premium quality through:

- Soft pink editorial color palette
- Cormorant Garamond serif headings
- Glassmorphism cards with subtle shadows
- Framer Motion micro-animations throughout
- Spacious, image-focused layouts

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

```
src/
├── assets/          # Portrait and gallery images
├── components/
│   ├── ui/          # Reusable UI elements
│   └── layout/      # Navbar + Footer
├── sections/        # Full-page sections (Hero, About, Works...)
├── hooks/           # useScrollAnimation, useMagneticButton
├── utils/           # Framer Motion animation variants
└── styles/          # Global CSS + Tailwind v4 tokens
```

## 🎨 Sections

1. **Floating Navigation** — Transparent blur navbar with CTA
2. **Hero** — Editorial headline, portrait, floating stat cards
3. **About** — Asymmetric layout, bio, skills, platform stats
4. **Featured Works** — Masonry gallery with category filters
5. **Video Showcase** — Featured video + carousel
6. **Brand Collaborations** — Luxury logo wall + marquee
7. **Statistics** — Animated count-up stat cards
8. **Services** — 6 glass cards with hover effects
9. **Testimonials** — Animated carousel with client quotes
10. **Contact** — Elegant form + social links
11. **Footer** — Minimal premium footer

## 🎯 Tech Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Framer Motion 12**
- **Lucide React** icons
- **Google Fonts** — Cormorant Garamond + Inter
